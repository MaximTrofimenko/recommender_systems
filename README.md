# Домашнее задание: книжный рекомендательный сервис

В работе используется датасет Goodbooks-10k. В папке `data` находятся оценки пользователей, информация о книгах и теги.

Основной файл проекта — `hw1.ipynb`.

## Логика решения

### Этап 1. Анализ данных

Сначала загружаются файлы `ratings.csv`, `books.csv`, `tags.csv` и `book_tags.csv`.

Выполняется небольшой EDA:

- изучается распределение оценок;
- анализируется активность пользователей;
- анализируется количество оценок у книг;
- строится график популярных тегов;
- рассчитывается разреженность матрицы пользователь–книга.

В данных видно смещение оценок в сторону 4 и 5, большое количество малоактивных пользователей и высокую разреженность матрицы.

### Этап 2. Базовые и контентные модели

Сначала строится простой бейзлайн: книги сортируются по среднему рейтингу, но учитываются только книги с достаточным количеством оценок.

Затем для каждой книги создаётся текстовый профиль из названия, автора и тегов. Профили переводятся в TF-IDF-векторы. Похожие книги находятся по косинусной близости.

Если `original_title` отсутствует, используется обычное `title`.

### Этап 3. Item-Based Collaborative Filtering

Оценки пользователей переводятся в разреженную матрицу `user_id × book_id`.

Для книг считается косинусная схожесть по оценкам пользователей. Оценка новой книги для пользователя получается как взвешенное среднее оценок похожих книг, которые пользователь уже оценивал.

### Этап 4. SVD

С помощью библиотеки Surprise данные делятся на обучающую и тестовую части. На обучающей части строится модель SVD, после чего считается RMSE.

Для пользователя модель предсказывает оценки всех книг, которые он ещё не оценивал, и возвращает книги с максимальным прогнозом.

### Этап 5. Сравнение моделей

Релевантными считаются книги, которым пользователь поставил оценку не ниже 4.

Для Popularity, Item-Based CF и SVD считаются:

- Precision@5;
- Recall@5;
- nDCG@5.

Оценка проводится на отложенной тестовой выборке. Для ускорения используется одинаковая случайная подвыборка пользователей для всех моделей.

### Этап 6. Гибридная модель

Гибрид объединяет SVD и контентную модель:

- для нового пользователя используются популярные книги;
- для известного пользователя учитываются SVD и сходство с понравившимися книгами;
- для новой книги используется её текстовый профиль.

По проведённому сравнению лучшей моделью среди базовых вариантов оказался SVD, но абсолютные значения top-N метрик остались низкими. Это связано с разреженностью данных и небольшим количеством оценок у многих пользователей.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

После этого открыть `hw1.ipynb` и выполнить ячейки сверху вниз.
